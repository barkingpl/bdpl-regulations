How to Use

Quick steps

  1. Export the entries from the registration tracker as a CSV (Google Sheets: File → Download → Comma-separated values) or save as XLSX. Only the first sheet of an XLSX is read.
  2. Load Entries: drag the file onto the upload box (or click it). Check the preview shows the right number of entrants, format, venues and draw size.
  3. Competition Settings: enter the competition name, race-to and date, then click Confirm & Proceed.
  4. Generate Draw: click Generate Draw. Check that "Same-team R1 matchups" is 0 ✅. If not, click Redraw until it is.
  5. Click Lock Draw, then Print All Sheets. Each venue prints on its own A4 page. Choose "Save as PDF" in the print dialog to keep a copy. Make sure background graphics are turned on.

File columns

The headings must be on the first row. Upper or lower case doesn't matter, and extra columns are ignored. Download entries-template.csv for an example.

ColumnWhat to put in it
DescriptionRequired. Player name, or for pairs Name & Name. If any entry contains " & ", the whole competition is treated as Pairs.
TeamThe player's league team. Used to keep team-mates apart in round 1 and, where possible, at the same venue.
OrganiserTRUE for the one entrant running each venue (their name is printed on that venue's sheet). Leave blank for everyone else.
VenueFor an organiser: the venue they run. For anyone else: fills in a venue to seed them there (fix them to it). Leave blank to place them at random.
Entered Date, Payment StatusNot used by the generator. Unpaid entrants are still included, so delete those rows first if they shouldn't be in the draw.

How venues are worked out

  • Multi-venue event: mark one organiser per venue. You get one bracket per organiser venue. Unseeded entrants are spread evenly across them, avoiding team-mates where possible.
  • No organisers marked: each different value in the Venue column becomes a venue.
  • No organisers and no venues: everyone goes into a single "Main Draw".
  • Draw size: every venue uses the same bracket size, the next power of 2 (8, 16, 32, 64…) that fits the biggest venue. Empty places become byes.

Loading from the repo

Instead of uploading, you can commit the CSV to the draw/ folder of the GitHub repo. Then type its path (e.g. competitions/henry-thorpe-2026.csv) or a full URL into the box and click Load.

Troubleshooting

  • "Missing required column: Description": the heading row is missing or misspelt, or there are blank rows above it.
  • Venue count or draw size looks wrong in the preview: check the Organiser and Venue columns. Typos in a venue name create an extra venue, e.g. "Keith Davis" vs "Keith Davies".
  • Print has no colours: tick "Background graphics" in the print dialog's settings.
